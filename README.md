# Уютный дом — контент недель

VK-сообщество «Уютный дом» (https://vk.ru/creativsss).

Каждая неделя — в `weeks/<дата понедельника>/` (структура как папка `week/` у скилла «уютный дом — облачная неделя»):
картинки `<код>.jpg`, тексты постов `txt/`, клипы `clip_<код>.mp4`, описания клипов `desc/`, планы `plan_posts.json` и `plan_clips.json`, таблица `table.md`, статус `progress.md`.

Чтобы работать с неделей в новой сессии: скопировать `weeks/<дата>/` в рабочую папку как `week/`.
